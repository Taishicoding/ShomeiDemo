# Shōmei QR experience

The active experience is a static site with three clean routes:

- `/` — legacy-style property dashboard that transitions on click to the reveal screen, then opens the hub.
- `/hub` — four interactive infrastructure views, with a persistent Reveal the Secret link and unit economics banner.
- `/reveal` — SMS-first product explanation.

All feature actions stay in the browser. No messages, contractor dispatches, payments, ledger entries, statutory filings, or owner votes are sent or recorded.

## Deployment

See [VERCEL.md](VERCEL.md) for project settings and the Git or CLI deployment path. No framework, package installation, or build command is required.

The supplied wordmark and S mark remain in `assets/`. The full-red poster has been removed. The original template reference remains in `templates/`.
